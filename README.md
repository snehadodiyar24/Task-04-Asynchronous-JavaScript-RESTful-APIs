# Task 04 — Asynchronous JavaScript & RESTful APIs

A responsive live weather dashboard using vanilla JavaScript, Fetch API, async/await, and the public Open-Meteo geocoding and forecast APIs.

## Features
- Search weather by city name
- Fetch city coordinates using Open-Meteo geocoding
- Fetch current weather and hourly forecast data
- Show temperature, conditions, humidity, apparent temperature, wind speed, cloud cover, and hourly outlook
- Handle failed HTTP requests, unknown cities, incomplete responses, and network errors
- Responsive layout for desktop and mobile
- Accessible search form and live status messages

## Run
Open `index.html` in a modern browser with an internet connection. No API key or npm installation is required.

## APIs
- Geocoding: https://geocoding-api.open-meteo.com/v1/search
- Forecast: https://api.open-meteo.com/v1/forecast
- Provider: https://open-meteo.com/
